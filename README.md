# Epidemic / COVID-19 Data Tracker

## Description

This project was developed as part of the Programming Fundamentals course.

The application analyzes COVID-19 data using Python.

## Features

- Load COVID-19 CSV dataset
- Analyze daily cases
- Calculate 7-day rolling average
- Calculate growth rate
- Detect outbreak peak
- Compare countries
- Generate graphs
- Export summary report

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Dataset

This project uses the public dataset provided by Our World in Data.

https://covid.ourworldindata.org/data/owid-covid-data.csv
